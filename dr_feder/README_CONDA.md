# Conda / Mamba Environment Reference Guide
## Federated Diabetic Retinopathy Suite

Ghid pentru utilizarea mediilor Anaconda, Miniconda și Mamba cu fișierul `environment.yml`.

---

## 1. Comenzi Rapide

```bash
# Creare mediu
conda env create -f environment.yml

# Activare
conda activate dr_fedml_suite

# Dezactivare
conda deactivate
```
