Deep Learning Model Architectures Overview

ResNet-50 Baseline

50-layer residual deep convolutional network with identity skip connections, adapted for histopathological input representations.

AlexNet Baseline

Deep 8-layer benchmark CNN with 11x11 conv filters and max pooling, serving as standard baseline.

ZFNet Baseline

Zeiler & Fergus architecture featuring 7x7 conv1 filters with stride 2 for fine-grained cell structure feature visualization.

Bionnica (Custom)

Custom deep architecture tailored for colorectal polyp morphology feature extraction with rule-based premalignancy evaluation layers.

BFNet (Custom)

Custom deep architecture optimized for cervical cell pap smear cytology feature extraction and nuclear-cytoplasmic ratio rule layers.
